MONSTER COLLECTION - primeira versão

Como usar no iPhone:
1. Hospede os arquivos index.html e manifest.json em um site HTTPS (ex.: GitHub Pages).
2. Abra o endereço no Safari do iPhone.
3. Compartilhar > Adicionar à Tela de Início.

Os dados ficam salvos localmente no navegador (localStorage). Faça backup/exportação antes de limpar os dados do Safari.

O catálogo inicial é uma seleção de exemplo, NÃO uma base mundial completa. Você pode cadastrar novas latas pelo botão +.
